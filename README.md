# DataMasterV2

Projeto profissional de Engenharia de Dados em Azure + Databricks, combinando geração automática de dados, infraestrutura como código, Delta Live Tables, governança, observabilidade e CI/CD.

## Arquitetura resumida

GitHub Actions  Terraform Azure  Azure Function  ADLS Gen2  Databricks DLT Bronze/Silver/Gold  Grafana/Monitoramento.

## Ambiente inicial

- Ambiente: dev
- Região Azure: brazilsouth
- Containers: source e rejeitados
- Branch de deploy: dev
